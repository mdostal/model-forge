# Project: Clarabel's Playset — Hole / Bracket

Second reverse-engineering job, run the **same loop** as the furniture brackets once that one lands:
1. Photograph the broken/missing part + the **hole it fits** (multiple angles + a ruler in frame).
2. Describe the failure ("the sink / hole is ___, the part that goes here does ___").
3. Drop **real caliper measurements** into the table below.
4. Model in CAD → tweak in Bambu Studio → slice grey PLA/PETG → test-fit → iterate.

Perfect **grey functional print** — no color, no smoothness needed. If it *does* need to be smooth later, see the quality levers in `../../docs/photo-to-3d.md`.
